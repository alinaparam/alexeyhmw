Task A · conditionals

Real or imaginary?

First conditional — реально, вполне может случиться: If + Present Simple, will + V.
If the “bank” calls me, I’ll hang up.

Second conditional — «если бы», воображаемо или маловероятно: If + Past Simple, would + V.
If a scammer called me, I’d laugh. If I were you, I’d block him.

⚠️ После if никогда нет will / would: If he will call → If he calls.

Сначала реши: реально или «если бы»? Потом выбери форму. После ответа увидишь объяснение.

Task B · unless / until / as soon as

Three tricky words

unless= if … not, «если не». Don’t pay unless you’re sure. (= if you are not sure)
⚠️ Без второго not: unless you don’t check → unless you check.
until= «пока не», «до тех пор, пока». I won’t answer until I check the number.
В русском есть «не», в английском его нет: until I don’t check.
as soon as= «как только». Call the bank as soon as you notice something strange.

Главное правило: после unless / until / as soon as — Present Simple, даже если речь о будущем. as soon as I will get home → as soon as I get home. Will — только в другой части: I’ll call you as soon as I get home.
